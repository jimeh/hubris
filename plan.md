# Plan: hubris2 Initial Web Application

## Goal

Build the initial web-based application with:

1. Sidebar listing projects (repositories)
2. Ability to add repositories to the project list
3. Select a project → view with multiple tabs for terminals

Web-first (Axum server, accessed from any browser). Desktop wrapping deferred.

## Stack Decisions (from research)

- **Backend**: Rust, Axum 0.8, tokio
- **Frontend**: Svelte 5, Vite 7, TypeScript
- **Styling**: Tailwind CSS v4 + shadcn-svelte (Bits UI primitives)
- **Terminal**: xterm.js v6 (with WebGL addon, behind adapter for future
  ghostty-web swap)
- **PTY**: portable-pty 0.9
- **Static serving**: tower-http ServeDir (dev), memory-serve (production)
- **State**: In-memory (DashMap for sessions), JSON file for project list
- **Package manager**: pnpm

### 1.3 Project API (`crates/server/src/api/projects.rs`)

Project model:

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Project {
    pub id: String,       // uuid
    pub name: String,     // display name (repo dirname)
    pub path: String,     // absolute path to repo root
}
```

Endpoints:

| Method | Path              | Description                |
|--------|-------------------|----------------------------|
| GET    | /api/projects     | List all projects          |
| POST   | /api/projects     | Add project (path in body) |
| DELETE  | /api/projects/:id | Remove project from list   |

`POST /api/projects` body:

```json
{ "path": "/home/user/repos/myproject" }
```

Server validates path exists and is a directory. Derives `name` from the
directory basename. Generates a uuid for `id`. Appends to `projects.json`.

Reading/writing `projects.json` uses `tokio::fs` with a simple
read-modify-write pattern. No concurrent write concern for a single-user
tool — a `tokio::sync::Mutex` around file access is sufficient.

```rust
pub async fn list_projects(
    State(state): State<AppState>,
) -> Result<Json<Vec<Project>>, StatusCode> {
    let projects = load_projects(&state).await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    Ok(Json(projects))
}

pub async fn add_project(
    State(state): State<AppState>,
    Json(req): Json<AddProjectRequest>,
) -> Result<(StatusCode, Json<Project>), StatusCode> {
    let path = PathBuf::from(&req.path);
    if !path.is_dir() {
        return Err(StatusCode::BAD_REQUEST);
    }
    let name = path.file_name()
        .and_then(|n| n.to_str())
        .unwrap_or("unnamed")
        .to_string();
    let project = Project {
        id: uuid::Uuid::new_v4().to_string(),
        name,
        path: req.path,
    };
    let mut projects = load_projects(&state).await
        .unwrap_or_default();
    projects.push(project.clone());
    save_projects(&state, &projects).await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    Ok((StatusCode::CREATED, Json(project)))
}

pub async fn delete_project(
    State(state): State<AppState>,
    Path(id): Path<String>,
) -> StatusCode {
    let mut projects = load_projects(&state).await
        .unwrap_or_default();
    let before = projects.len();
    projects.retain(|p| p.id != id);
    if projects.len() == before {
        return StatusCode::NOT_FOUND;
    }
    save_projects(&state, &projects).await
        .unwrap_or(());
    StatusCode::NO_CONTENT
}
```

Helper functions `load_projects`/`save_projects` do file I/O with
`tokio::fs::read_to_string` / `tokio::fs::write`.

### 1.4 Terminal WebSocket (`crates/server/src/api/terminal.rs`)

Endpoint: `GET /api/terminal/ws?project_id=X`

On WebSocket upgrade:

1. Look up project by ID to get the working directory
2. Spawn PTY with shell in that directory
3. Bridge PTY ↔ WebSocket (per research3.md §3.4)

Also handle resize messages from the client. Use a simple protocol:

- Binary frames = raw terminal data (both directions)
- Text frames = JSON control messages:
  - `{"type":"resize","cols":80,"rows":24}`

```rust
pub async fn ws_handler(
    State(state): State<AppState>,
    Query(params): Query<TerminalParams>,
    ws: WebSocketUpgrade,
) -> Result<impl IntoResponse, StatusCode> {
    let projects = load_projects(&state).await
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    let project = projects.iter()
        .find(|p| p.id == params.project_id)
        .ok_or(StatusCode::NOT_FOUND)?;
    let cwd = project.path.clone();
    Ok(ws.on_upgrade(move |socket| {
        handle_terminal(socket, cwd, state)
    }))
}
```

The `handle_terminal` function follows research3.md §3.4 closely: spawn PTY
via portable-pty, use bounded mpsc channel, spawn_blocking for PTY reader,
adaptive batching with 4ms timer for high-throughput output.

### 1.5 PTY Session Manager (`crates/server/src/pty/session.rs`)

```rust
pub struct PtySession {
    pub id: String,
    pub master: Box<dyn portable_pty::MasterPty + Send>,
    pub child: Box<dyn portable_pty::Child + Send + Sync>,
    pub created_at: std::time::Instant,
}
```

For this initial phase, sessions are ephemeral — they live only as long as the
WebSocket is connected. No reconnection support yet (that's a later
enhancement). When the WebSocket closes, the PTY is dropped, which sends
SIGHUP to the shell.

### 1.6 Server Entry Point (`crates/server/src/main.rs`)

```rust
#[tokio::main]
async fn main() {
    tracing_subscriber::fmt()
        .with_env_filter(
            tracing_subscriber::EnvFilter::from_default_env()
                .add_directive("hubris2_server=debug".parse().unwrap())
        )
        .init();

    let data_dir = if cfg!(debug_assertions) {
        PathBuf::from("./data")
    } else {
        dirs::home_dir()
            .expect("no home directory")
            .join(".hubris")
    };
    tokio::fs::create_dir_all(&data_dir).await
        .expect("failed to create data dir");

    let state = AppState::new(data_dir);

    let api = Router::new()
        .route("/projects", get(list_projects).post(add_project))
        .route("/projects/{id}", delete(delete_project))
        .route("/terminal/ws", get(ws_handler));

    // In dev, frontend served by Vite dev server.
    // CORS allows Vite's localhost:5173.
    let cors = CorsLayer::new()
        .allow_origin("http://localhost:5173".parse::<HeaderValue>().unwrap())
        .allow_methods([Method::GET, Method::POST, Method::DELETE])
        .allow_headers([CONTENT_TYPE]);

    let app = Router::new()
        .nest("/api", api)
        .layer(cors)
        .layer(TraceLayer::new_for_http())
        .with_state(state);

    let addr = "0.0.0.0:3001";
    tracing::info!("listening on {}", addr);
    let listener = tokio::net::TcpListener::bind(addr).await.unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

Port 3001 for the API server. Vite dev server on 5173. Vite proxies
`/api/*` to 3001 in dev (configured in `vite.config.ts`).

For production, frontend assets served by the Axum server directly via
`tower-http::ServeDir` with SPA fallback (add after frontend build step).

```typescript
import type { Project } from './types';

const BASE = '/api';

export async function listProjects(): Promise<Project[]> {
  const res = await fetch(`${BASE}/projects`);
  if (!res.ok) throw new Error(`${res.status}`);
  return res.json();
}

export async function addProject(
  path: string
): Promise<Project> {
  const res = await fetch(`${BASE}/projects`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ path }),
  });
  if (!res.ok) throw new Error(`${res.status}`);
  return res.json();
}

export async function deleteProject(id: string): Promise<void> {
  const res = await fetch(`${BASE}/projects/${id}`, {
    method: 'DELETE',
  });
  if (!res.ok) throw new Error(`${res.status}`);
}

export function terminalWsUrl(projectId: string): string {
  const proto = location.protocol === 'https:' ? 'wss:' : 'ws:';
  return `${proto}//${location.host}/api/terminal/ws?project_id=${projectId}`;
}
```

### 2.5 xterm.js Implementation (`frontend/src/lib/terminal/xterm.ts`)

```typescript
import { Terminal } from '@xterm/xterm';
import { WebglAddon } from '@xterm/addon-webgl';
import { FitAddon } from '@xterm/addon-fit';
import { WebLinksAddon } from '@xterm/addon-web-links';
import '@xterm/xterm/css/xterm.css';
import type { TerminalAdapter } from './adapter';

export function createXtermAdapter(
  opts?: { fontSize?: number; fontFamily?: string }
): TerminalAdapter {
  const term = new Terminal({
    fontSize: opts?.fontSize ?? 14,
    fontFamily: opts?.fontFamily
      ?? "'JetBrains Mono', 'Fira Code', monospace",
    theme: {
      background: '#1e1e2e',
      foreground: '#cdd6f4',
      cursor: '#f5e0dc',
    },
    cursorBlink: true,
    scrollback: 10000,
  });

  const fitAddon = new FitAddon();
  const dataListeners: Array<(data: string) => void> = [];

  return {
    open(container: HTMLElement) {
      term.open(container);
      term.loadAddon(fitAddon);
      term.loadAddon(new WebLinksAddon());
      try {
        const webgl = new WebglAddon();
        webgl.onContextLoss(() => {
          webgl.dispose();
        });
        term.loadAddon(webgl);
      } catch {
        // WebGL not available, use default canvas
      }
    },
    write(data: string | Uint8Array) {
      term.write(data);
    },
    onData(cb: (data: string) => void) {
      return term.onData(cb);
    },
    resize(cols: number, rows: number) {
      term.resize(cols, rows);
    },
    fit() {
      fitAddon.fit();
    },
    get rows() { return term.rows; },
    get cols() { return term.cols; },
    focus() { term.focus(); },
    dispose() { term.dispose(); },
  };
}
```

### 2.6 Project Store (`frontend/src/lib/stores/projects.svelte.ts`)

Using Svelte 5 runes:

```typescript
import { listProjects, addProject, deleteProject } from '$lib/api';
import type { Project } from '$lib/types';

let projects = $state<Project[]>([]);
let selected = $state<Project | null>(null);
let loading = $state(false);
let error = $state<string | null>(null);

export function getProjectStore() {
  async function refresh() {
    loading = true;
    error = null;
    try {
      projects = await listProjects();
    } catch (e) {
      error = (e as Error).message;
    } finally {
      loading = false;
    }
  }

  async function add(path: string) {
    const project = await addProject(path);
    projects = [...projects, project];
    return project;
  }

  async function remove(id: string) {
    await deleteProject(id);
    projects = projects.filter((p) => p.id !== id);
    if (selected?.id === id) selected = null;
  }

  function select(project: Project) {
    selected = project;
  }

  return {
    get projects() { return projects; },
    get selected() { return selected; },
    get loading() { return loading; },
    get error() { return error; },
    refresh,
    add,
    remove,
    select,
  };
}
```

**Important**: Module-level `$state` runes work in Svelte 5 `.svelte.ts`
files. Name this file `projects.svelte.ts` for runes to work outside
components.

### 2.7 Tab Store (`frontend/src/lib/stores/tabs.svelte.ts`)

Similarly `tabs.svelte.ts`:

```typescript
import type { Tab } from '$lib/types';

let tabs = $state<Tab[]>([]);
let activeTabId = $state<string | null>(null);

export function getTabStore() {
  function addTerminal(): Tab {
    const id = crypto.randomUUID();
    const num = tabs.filter(t => t.type === 'terminal')
      .length + 1;
    const tab: Tab = {
      id,
      label: `Terminal ${num}`,
      type: 'terminal',
    };
    tabs = [...tabs, tab];
    activeTabId = id;
    return tab;
  }

  function close(id: string) {
    tabs = tabs.filter((t) => t.id !== id);
    if (activeTabId === id) {
      activeTabId = tabs[tabs.length - 1]?.id ?? null;
    }
  }

  function activate(id: string) {
    activeTabId = id;
  }

  function reset() {
    tabs = [];
    activeTabId = null;
  }

  return {
    get tabs() { return tabs; },
    get activeTabId() { return activeTabId; },
    addTerminal,
    close,
    activate,
    reset,
  };
}
```

```svelte
                     : 'text-muted-foreground hover:text-foreground'
                   }"
            onclick={() => tabStore.activate(tab.id)}
          >
            {tab.label}
            <button
              class="ml-1 rounded-sm opacity-60
                     hover:opacity-100"
              onclick|stopPropagation={
                () => tabStore.close(tab.id)
              }
            >
              <X class="h-3 w-3" />
            </button>
          </button>
        {/each}
      </div>
    {/if}
    <Button
      variant="ghost"
      size="icon-sm"
      class="ml-1 shrink-0"
      onclick={() => tabStore.addTerminal()}
    >
      <Plus class="h-4 w-4" />
    </Button>
  </div>

  <div class="relative flex-1 overflow-hidden">
    {#each tabStore.tabs as tab (tab.id)}
      <div
        class="absolute inset-0"
        class:hidden={tab.id !== tabStore.activeTabId}
      >
        {#if tab.type === 'terminal'}
          <TerminalTab
            projectId={project.id}
            visible={tab.id === tabStore.activeTabId}
          />
        {/if}
      </div>
    {/each}
    {#if tabStore.tabs.length === 0}
      <div class="flex h-full items-center justify-center
                  text-muted-foreground">
        <p>Click + to open a terminal</p>
      </div>
    {/if}
  </div>
</div>
```

Tabs are kept alive when switching (not destroyed) — terminal state preserved.
Use `class:hidden` with `display: none` to hide inactive tabs, not `{#if}`.
Each tab pane is `absolute inset-0` so it fills the content area.

Note: We're using a custom tab bar rather than shadcn `Tabs.*` because we
need close buttons on each tab and a dynamic "+" button — the built-in Tabs
component expects static, predeclared values. The custom bar uses the same
Tailwind theme tokens for visual consistency.

#### `TerminalTab.svelte`

The critical component. Creates WebSocket connection, bridges to xterm.js
via the adapter.

```svelte
<script lang="ts">
  import { onMount, onDestroy } from 'svelte';
  import { createXtermAdapter } from '$lib/terminal/xterm';
  import { terminalWsUrl } from '$lib/api';
  import type { TerminalAdapter } from '$lib/terminal/adapter';

  let { projectId, visible } = $props<{
    projectId: string;
    visible: boolean;
  }>();

  let containerEl: HTMLDivElement;
  let terminal: TerminalAdapter | null = null;
  let ws: WebSocket | null = null;

  onMount(() => {
    terminal = createXtermAdapter();
    terminal.open(containerEl);

    ws = new WebSocket(terminalWsUrl(projectId));
    ws.binaryType = 'arraybuffer';

    ws.onopen = () => {
      // Send initial size
      ws!.send(JSON.stringify({
        type: 'resize',
        cols: terminal!.cols,
        rows: terminal!.rows,
      }));
      terminal!.focus();
    };

    ws.onmessage = (ev) => {
      terminal!.write(new Uint8Array(ev.data));
    };

    ws.onclose = () => {
      terminal!.write('\r\n[Connection closed]\r\n');
    };

    terminal.onData((data) => {
      if (ws?.readyState === WebSocket.OPEN) {
        // Send user input as binary
        ws.send(new TextEncoder().encode(data));
      }
    });

    // Handle resize
    const resizeObserver = new ResizeObserver(() => {
      if (visible) {
        terminal!.fit();
        if (ws?.readyState === WebSocket.OPEN) {
          ws.send(JSON.stringify({
            type: 'resize',
            cols: terminal!.cols,
            rows: terminal!.rows,
          }));
        }
      }
    });
    resizeObserver.observe(containerEl);

    return () => {
      resizeObserver.disconnect();
    };
  });

  // Fit when tab becomes visible
  $effect(() => {
    if (visible && terminal) {
      // Small delay for layout to settle
      requestAnimationFrame(() => terminal!.fit());
    }
  });

  onDestroy(() => {
    ws?.close();
    terminal?.dispose();
  });
</script>

<div class="terminal-container" bind:this={containerEl}></div>

<style>
  .terminal-container {
    width: 100%;
    height: 100%;
  }
</style>
```
